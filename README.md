# Waypoint Assist for Xaero's Minimap

Xaero's Minimap/Worldmap addon that adds automatic waypoints as well as presets, shortcuts, custom colors, and more.

Designed for use with TerraFirmaGreg/TerraFirmaCraft, for easier management of waypoints when you want to mark all those surface ores you find on the map.
Comes with a configuration preset for TerraFirmaGreg.

This mod is for Minecraft 1.20.1, and uses Forge 47.4.13 (__targets TFG-Modern *0.13.7*__).

---


## Planned Features
- [x] __Waypoint Presets__: pre-define attributes of a waypoint such as name, color, abbreviation, and group to automatically fill in these details in the "New Waypoint" menu.
- [ ] __Auto-Waypoints__: Presets can be assigned to blocks/items that when interacted with or picked up in the world, creates a new waypoint automatically.
- [ ] __History/Memory__: Option to autofill in/remember what was last entered, and ability to undo/redo.
- [ ] __In-Game & Menu Keybind Shortcuts__: keybinds for in-game and in-menu waypoint preset use/creation.
- [ ] __Longer Abbreviations__: allow up to 4 characters for the abbreviation, with option to render the last 2 in a smaller font.
- [ ] __Custom Color Presets__: Allow the input of a custom color, and save new color presets for use later.
- [ ] __Bulk Organization Operations__: Waypoint organization operations to bulk rename, change color, move to different waypoint set, and more based on search/regex criteria.
